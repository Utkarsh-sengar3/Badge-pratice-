# Badge-pratice-

A small practice repository for learning GitHub workflows and achievements.

## What this repository demonstrates

- Creating branches from `main`
- Making focused documentation changes
- Opening and merging pull requests
- Practicing a review-free merge when repository rules allow it

## Contribution workflow

1. Create a feature branch.
2. Make a useful, focused change.
3. Open a pull request against `main`.
4. Check the diff and repository rules before merging.

This README is maintained as part of GitHub workflow practice.
